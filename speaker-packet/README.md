# Trillium Smith — Org Packet

**Software developer & open-source contributor | Hands-free coding with Talon Voice + Cursorless**

> For: community orgs, meetups, conferences, accessibility groups, schools, and teams who want to host a talk, demo, or workshop.

This folder is everything an org needs to introduce, host, and share Trillium's work.

## What's in here

- `Trillium-Smith-Org-Packet.md` — the full booklet (start here, prints cleanly)
- `Trillium-Smith-Org-Packet.html` — same booklet as a single file (headshot embedded), open in browser → Print → Save as PDF
- `Trillium-Smith-One-Pager-Meetup.md` / `.html` — 1-page meetup variant: event title, copy-paste announcement, 60-min run-of-show, room checklist, follow-up email
- `../images/TrilliumSmith_headshot_web.jpeg` — web-optimized headshot (1000px, 149K)
- `../images/TrilliumSmith_headshot_web.webp` — same headshot as WebP (115K)
- `../images/TrilliumSmith_headshot.jpeg` — full-res original (3024px, print)

## How an org uses this

1. **Announce:** copy the Official Blurb + headshot to your event page / flyer / newsletter.
2. **Plan:** pick a format (talk, live demo, workshop, Q&A — all in the packet).
3. **Host:** follow the 1-page tech checklist in the packet.
4. **Share:** send attendees the links section after the event.
